# 数据源配置（重要 · 从 0 还原必读）

V15Plus 的评分、回测、扫描全部依赖**本地行情数据**。这份文档说明每个数据源从哪来、
怎么配、缺了会怎样——照着做即可从零跑通。

## 数据源总览

| 数据 | 来源 | 是否需要配置 | 缺失影响 |
|---|---|---|---|
| **日线 K 线**（个股 / 板块指数） | **通达信本地文件** | ✅ **必须配置** | 无法选股/回测（核心阻塞） |
| 5 分钟 K 线 | 通达信本地文件 | 可选 | 分时相关功能降级 |
| 新闻 | akshare（联网） | 无需配置 | 新闻/情绪模块降级 |
| 板块涨跌 | 同花顺 | 无需配置 | 板块共振降级 |
| 板块资金流 | 东方财富（浏览器） | 可选 | 板块动力降级为中性 |
| 港美股 | 新浪财经（联网） | 无需配置 | 跨市场模块降级 |

> 设计原则：**除通达信外，其余数据源缺失都不会报错**，对应模块自动降级为中性值，
> 主评分流程仍可运行。

---

## 一、通达信本地数据（必配）

### 1.1 为什么需要

V15Plus 的日线数据**不依赖任何在线接口**，而是直接读取你本机**通达信客户端**下载的
`.day` 文件。这样做的好处是数据稳定、无频率限制、完全离线可用。

### 1.2 安装与下载数据

1. 安装**通达信**金融终端（任意券商版/免费版均可）
2. 打开通达信，进入 **系统 → 盘后数据下载**（或快捷键下载每日数据）
3. 勾选：
   - **日线数据**（必须）—— 个股 + 板块指数
   - 5 分钟数据（可选，供分时模块使用）
4. 下载范围建议选**全部 A 股**、**足够长的历史**（回测需要至少 3 年）

> 板块数据：V15Plus 的板块动力用 `sh880xxx.day`（通达信板块指数文件）。
> 下载时确保包含**板块指数**，否则板块动力会降级。

### 1.3 确认数据目录结构

通达信的数据目录长这样（**带 `vipdoc` 的那一层就是我们要的 `TDX_ROOT`**）：

```
D:\通达信\                     ← TDX_ROOT_PATH 就填这一层
└── vipdoc\
    ├── sh\lday\sh600000.day   ← 上海市场日线
    ├── sz\lday\sz000001.day   ← 深圳市场日线
    ├── bj\lday\bj430047.day   ← 北京市场日线（如有）
    └── sh\lday\sh880515.day   ← 板块指数日线
```

### 1.4 配置路径

设置环境变量 `TDX_ROOT_PATH` 为上面那一层目录（**不要**包含 `vipdoc`）：

- **Windows（临时）**：`set TDX_ROOT_PATH=D:\通达信`
- **Windows（永久）**：`setx TDX_ROOT_PATH "D:\通达信"`（重新打开终端生效）
- **PowerShell**：`$env:TDX_ROOT_PATH = "D:\通达信"`
- **Linux / macOS**：`export TDX_ROOT_PATH=/path/to/tdx`
- **或写进 `.env`**：`TDX_ROOT_PATH=D:\通达信`

> 常见安装位置：`D:\通达信`、`C:\new_tdx`、`C:\Program Files\通达信`。
> 程序默认值是 `D:\通达信`；若你的路径不同，**必须**设置此变量。

### 1.5 验证是否生效

```bash
python -c "import os; p=os.environ.get('TDX_ROOT_PATH', r'D:\通达信'); print('TDX_ROOT =', p); print('存在:', os.path.exists(os.path.join(p,'vipdoc')))"
```

输出 `存在: True` 即配置正确。然后：

```bash
python start.py     # 打开 GUI，能正常读取行情/画出 K 线即成功
```

### 1.6 保持数据新鲜

通达信需要**每天盘后手动或自动下载**当日数据，否则程序读到的还是旧数据。
程序里 `kline_watcher.py` 会检测数据是否更新到今日，并提示你先打开通达信下载。

## 二、新闻数据（akshare，无需配置）

新闻通过 `akshare` 实时抓取，`pip install akshare` 后即可用。
无需任何密钥。若网络受限或接口变动，新闻模块会自动降级，不影响评分。

相关模块：`_internal/v14_news_provider.py`、`_plus_/news_distiller.py`、`_plus_/sentiment_quant.py`。

---

## 三、板块数据

| 维度 | 来源 | 配置 |
|---|---|---|
| 板块涨跌 | 同花顺（内置映射 `_internal/sector_map.json`） | 无需配置 |
| 板块资金流 | 东方财富页面（经 `bb-browser` 或其他方式抓取） | 可选，见下 |

板块资金流用于 `_plus_/sector_power.py` 的动力评分。若抓取不到，该维度自动降级为
中性值（50 分 / ×1.0），评分仍会输出。

---

## 四、港美股 / 跨市场（新浪财经，无需配置）

跨市场情绪通过新浪财经接口获取，联网即可，无需配置。

---

## 五、故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 启动后没有 K 线、选股为空 | `TDX_ROOT_PATH` 未配置或路径错误 → 按 1.4 / 1.5 检查 |
| 板块动力全是中性值 | 通达信未下载板块指数（`sh880*.day`） |
| 数据是旧的 | 打开通达信执行盘后下载当日数据 |
| 新闻/情绪为空 | akshare 网络问题，可忽略 |
| 提示"找不到 .day 文件" | 路径填成了 `...\vipdoc`，应只填到「通达信」这一层 |

---

## 六、完整还原清单（从 0 到跑通）

1. 安装 **Python 3.11+**
2. `git clone` 本仓库 → `pip install -r requirements.txt`
3. 安装**通达信**并下载**日线 + 板块**盘后数据
4. 设置 `TDX_ROOT_PATH` 指向通达信安装目录（含 `vipdoc` 的那一层）
5. （可选）复制 `.env.example` → `.env`，填 `DEEPSEEK_KEY` 等
6. 编辑 `self_stock.txt` 为你的自选股
7. `python start.py` 启动

有云端同步 / 消息推送需求时，再参考 [DEPLOYMENT.md](DEPLOYMENT.md) 与
[CONFIGURATION.md](CONFIGURATION.md)。
